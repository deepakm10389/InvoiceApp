Import bills

Load bill headers extracted from the old .NET app (scripts/seed-data/invoices.json). Import clients & items first. Matching is by client name. Duplicates (same client + bill no + date + total) are skipped.

The old ManageBill.aspx screen only exposes bill headers (number, client, date, totals). Line-item detail is not available from Edit, so each imported bill is stored as one summary line for the taxable subtotal (GST recalculated at 18% CGST+SGST). Bills that had number 0 on the old site get the next free bill number.
